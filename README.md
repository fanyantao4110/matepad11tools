# matepad11工具箱
这款 华为MatePad 11 综合工具箱 是一款基于 Windows 批处理（.bat）编写的图形化菜单工具，专为华为 MatePad 11（型号 DBY-W09）设计，集成了从驱动安装、解锁 Bootloader（BL）、刷入底层固件到刷入鸿蒙系统的完整流程，适合有一定刷机经验的用户使用。
注意！！！使用之前请下载底层文件放置到base目录里。如果没有base文件夹打开软件便可自动创建。下载地址：https://1821068313.share.123pan.cn/123pan/N3vxjv-EKnhh

🧰 主要功能一览
1. 安装驱动程序（第一步）
内置 ADB 驱动和高通 9008 驱动安装程序，一键启动对应的 .exe，无需手动寻找。
注意！源码里没有ADB 驱动，你需要从https://wwaxi.lanzoub.com/iyWbd426qprg 密码:bsjv 里下载并放置在tools\driver里

3. 解锁 BL（第二步）
支持两种系统版本：

鸿蒙2 - 鸿蒙3：通过 ADB 自动重启至 9008 模式，发送底层文件并刷写解锁镜像。

鸿蒙4：需要用户手动进入 9008 模式（探针/按键），再执行解锁。

解锁过程中包含文件完整性检查、设备状态检测（可重试）、解锁完成提示（若未自动重启会引导手动操作）。

3. 刷入底层（第三步）
扫描 base 文件夹内的 .zip 底层包，用户选择后自动解压到 cache 并刷入所有 .img 镜像。

刷入前自动清空 cache，刷完后再次清空，避免残留。

完成后会询问是否继续刷入系统，可无缝衔接下一步。

4. 刷入鸿蒙系统（第四步）
提供四种版本选择：鸿蒙2.0 / 3.0 / 4.0 / 4.2。

选择后会显示恢复出厂设置警告，确认后打开下载链接，用户下载 super.img 放入 system 目录。

刷入时自动检测 system 下的所有 .img 文件，按文件名对应分区名刷入。

支持手动刷入本地系统镜像（无需 JSON 配置），刷入后自动重启并提示如何进入 Recovery。

自动执行 fastboot -w 恢复出厂，并重启至 Recovery，提示用户手动清除数据确保正常启动。

5. 在线更新配置文件
系统版本列表（2.0.json、3.0.json、4.0.json、4.2.json）支持从 Gitee 在线下载或更新。

当本地缺少对应 JSON 时，刷机菜单会自动尝试下载；也可手动选择 [U] 一键更新全部配置。

6. 辅助工具
ADB 命令行：打开一个已配置好路径的命令行窗口，方便手动执行 adb/fastboot 命令。

设备管理器：快速打开 Windows 设备管理器，便于检查驱动状态。

🛡️ 安全与容错设计
首次启动显示免责声明，用户需同意才能进入。

刷机前会询问设备状态（正常开机/无法开机），正常则通过 ADB 自动重启至 Fastboot，否则引导手动进入。

所有设备检测（ADB / Fastboot）都支持显示日志、循环重试、按 Q 退出，避免因瞬间未识别而中断。

刷入镜像时，单个分区失败不会停止，而是记录并继续，最后统一显示失败分区列表，方便排查。

💡 适用人群
适合已经了解刷机风险、希望一站式完成 MatePad 11 解锁和刷机操作的用户。工具通过菜单引导降低了操作门槛，同时保留了手动模式和详细的错误提示，兼顾便捷性与可控性。

⚠️ 提醒：刷机、解锁可能导致设备变砖、数据丢失或失去保修，请务必提前备份重要数据，并确认自己理解相关风险。
